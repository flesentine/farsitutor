Farsi Daily Support

Help with lessons, audio, and saved progress

Pronunciation does not play

  • Confirm that media volume is turned up and silent mode is not blocking audio.
  • Try the slower pronunciation option in Settings.
  • Close and reopen the app or browser tab, then try again.

Progress looks incorrect

  • Make sure you are using the same device and browser profile where the progress was created.
  • Do not clear site data unless you intend to erase your learning history.
  • Use “Copy app details” in Settings when reporting the problem.

Resetting the app

Open Settings and choose Reset all learning progress. This removes saved words, lesson history, script results, streak information, and app preferences from the device.

Report a problem

For the current pre-release build, problems and feature requests can be submitted through the project’s public issue tracker. Do not include private personal information in a report.
