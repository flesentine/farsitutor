# App Store screenshot capture plan

Capture screenshots from the final iPhone simulator or physical build after the Capacitor/Xcode project exists. Product screenshots should show the real app, not reconstructed marketing mockups.

## Recommended 6.9-inch portrait set

Apple currently accepts these portrait dimensions for the largest iPhone display class:

- 1260 × 2736
- 1290 × 2796
- 1320 × 2868

Use one accepted size consistently for the full set. PNG screenshots must not contain transparency.

## Suggested five-screen story

1. **One short lesson each day** — Today screen with the current Farsi word.
2. **Hear real Persian pronunciation** — sentence practice with the audio action visible.
3. **Remember what you learn** — smart review question and rating controls.
4. **Learn the Persian alphabet** — today's letter, forms, and example word.
5. **Build a useful vocabulary** — My Words with learning status and due dates.

Keep status bars and device presentation consistent. Avoid claims or features that are not present in the submitted build.
